# AI Chatbot 🤖

An internship project — a full-stack AI chatbot built with Next.js 14, TypeScript, and Tailwind CSS.

## Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **AI**: (to be integrated in Week 2)

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Project Structure

```
ai-chatbot/
├── app/                  # Next.js App Router pages
│   ├── chat/             # Chat page
│   ├── api/chat/         # API route for AI responses
│   ├── layout.tsx        # Root layout
│   ├── page.tsx          # Homepage
│   └── globals.css       # Global styles
├── components/
│   ├── ui/               # Generic reusable UI (Button, Avatar, etc.)
│   ├── chat/             # Chat-specific components (ChatBubble, etc.)
│   └── layout/           # Layout components (Header, Footer)
├── hooks/                # Custom React hooks
├── types/                # TypeScript type definitions
└── utils/                # Utility/helper functions
```
